ヘルプ

このアプリについて
NovelAI 用のプロンプト（ポジティブ／ネガティブ）を管理・編集するための Web アプリです。ブラウザのローカルストレージに保存されるため、基本的にあなたの端末の中だけで完結します。

基本的な使い方

  • 上部のタブごとに、別々のプロンプトセットを管理できます（リネーム・削除・並び替え可）。
  • 「ポジティブプロンプト」「ネガティブプロンプト」のテキストエリアに、, 区切りで単語を入力します。
  • 各テキストエリア右上の「🗑」で内容を全削除できます。

候補・単語編集

  • 「候補」：カテゴリごとに登録した単語一覧から、タップでプロンプトに追加できます。複数選択モードでまとめて追加もできます。
  • 「編集」：候補カテゴリや単語の追加・削除・名前変更ができます。カテゴリごとに折りたたみ可能です。
  • 「単語編集」：現在のテキストをチップとして一覧表示し、長押しドラッグで並び替え・×ボタンで削除・プラス/マイナスや数値入力で 重み (数字::word::) を編集できます。

プリセット

  • 上部タブの「プリセット」から、ポジティブ／ネガティブ両方の本文を作成し、カテゴリごとに保存できます。
  • メイン画面の「プリセット」ボタンから、保存済みプリセットのポジ／ネガをそれぞれのテキストに一括で挿入できます。複数選択モードでまとめて適用も可能です。
  • プリセットモーダルの「適用方法」で「追加／上書き」を選んでから適用してください。

並び替えのヒント
単語編集モーダルでは、チップを「長押し → そのままドラッグ」で並び替えができます。複数選択モードを使うと、複数の単語をまとめて移動・強調・削除できます。

バックアップ
ヘッダーの 💾 ボタンから、現在の設定を JSON としてエクスポート／インポートできます。環境移行や万一のためのバックアップに使ってください。

バックアップ / 復元

このアプリの設定やタブ内容・候補・プリセットなどを、JSON 形式でバックアップできます。
「JSONを出力」で現在のデータを下のテキストエリアに表示し、コピーしてメモ帳などに保存してください。
復元するときは、保存しておいた JSON を貼り付けて「JSONを読み込んで復元」を押します。

※ 復元を実行すると、現在のデータはすべて上書きされます。
